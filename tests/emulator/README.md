# Emulador de Firestore para las pruebas

`firestore.rules` es una **copia** de `youwebit-platform/infra/platform/firestore.rules`
(la fuente de verdad). Si cambian las reglas allí, vuelve a copiarlas aquí para que las
pruebas del formulario sigan siendo fieles. Las reglas en sí se prueban en el repo de la
plataforma (`tests/rules`).
